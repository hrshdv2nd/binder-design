How to read this. Gates are binary admissibility: tighten pae and watch the funnel narrow and the rejection bars shift. Weights set how the admissible designs are ranked — push ddG to 0 and the shortlist reorders around interface confidence instead. The real craft is calibrating these from wet-lab results: score each metric on how well it separated real binders, reweight, repeat. Numbers here are synthetic, modelled on the spread a real RFdiffusion / BindCraft → AlphaFold2 → Rosetta pipeline produces — no wet-lab data is implied. The code that does this for real lives in the binder_triage repo.
